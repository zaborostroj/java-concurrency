# Примеры пулов потоков

Этот пакет демонстрирует использование ExecutorService для управления пулами потоков в Java.

## ExampleExecutorService

`ExampleExecutorService` демонстрирует базовое использование пулов потоков с помощью фреймворка `ExecutorService` Java.

Ключевые возможности:

- Создает фиксированный пул потоков с заданным количеством потоков
- Отправляет несколько задач на параллельное выполнение
- Управляет жизненным циклом задач (отправка, выполнение, завершение)
- Корректно завершает работу executor service для освобождения ресурсов
- Показывает примеры использования типов задач `Runnable` и `Callable`

Класс иллюстрирует, как пулы потоков могут эффективно переиспользовать потоки для множества задач, избегая накладных
расходов на создание новых потоков для каждой операции.
