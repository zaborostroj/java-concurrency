# Задача: Игра со спичками

https://coderun.yandex.ru/selections/algorithm-training-september-2025/problems/playing-with-matches/description

## Описание задачи

На столе лежит кучка из N спичек. Двое играют в такую игру. За один ход разрешается взять из кучки одну, две или три
спички, так чтобы оставшееся количество спичек не было простым числом (например, можно оставить в кучке 1 или 4 спички,
но нельзя оставить 2 или 3). Выигрывает тот, кто забирает последнюю спичку. Требуется определить, кто из игроков имеет
выигрышную стратегию.

## Формат ввода

Вводится одно число N (1≤N≤10000).

## Формат вывода

Выведите число 1, если при правильной игре победит первый игрок (который делает первый ход), или число 2, если при
правильной стратегии победит второй игрок.

## Ограничения

| Параметр            | Значение |
|---------------------|----------|
| Ограничение времени | 1 с      |
| Ограничение памяти  | 256 МБ   |

## Примеры

| Пример   | Ввод | Вывод |
|----------|------|-------|
| Пример 1 | 1    | 1     |
| Пример 2 | 2    | 1     |
| Пример 3 | 4    | 2     |

# Решение

Для любого количества спичек `N` будем считать выигрышным начинать игру первым, если
1. можно забрать все спички одним ходом
2. если хотя бы один из вариантов хода приводит к разрешённому количеству спичек, при котором для выигрыша нужно начинать вторым

В цикле от `1` до `N` считаем все выгодные позиции (даст сложность `О(n)`). На каждой итерации проверяем, допустим ли остаток при заборе 1, 2 или 3 спичек и смотрим, с какой позиции выгоднее начинать при данном остатке. Результат проверок складываем в массив.

    1 -> 1 => 1
    2 -> 2 => 1
    3 -> 3 => 1
    4 -> 3 => 2
    
    5 -> 1 => 1
    6 -> 2 => 1
    7 -> 1- 3 => 1
    8 -> 1- 3- 2 => 2
    9 -> 2- 3- 1 => 1

Проверка на простоту сделана перебором целых чисел от `2` до `sqrt(n)` включительно. Если нашли делитель, который делит `n` без остатка - число не простое. Сложность `O(sqrt(n))`.

Итоговая сложность `O(n * sqrt(n))`.
