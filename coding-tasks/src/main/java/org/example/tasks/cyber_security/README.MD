# Кибербезопасность

## Описание задачи

На работе у Васи требуют менять пароль каждую неделю, причём новый пароль не должен совпадать ни с одним из предыдущих.
Любимый Васин пароль — это строка s, состоящая из строчных английских букв. Этот пароль он использует первую неделю.
Придумывать и запоминать новые пароли Васе лень, поэтому он придумал правило, по которому он будет получать новый пароль
каждую неделю:

1. Берется исходный пароль s
2. В данном пароле можно выбрать любую пару букв и поменять их местами
3. Если такой пароль не совпадает ни с одним из тех, что уже были использованы, то этот пароль можно использовать

Определите, сколько недель Вася сможет генерировать новые пароли с учетом пароля s на первой неделе.

## Формат ввода

Вводится строка s (1 ≤ |s| ≤ 10^5), состоящая из строчных английских букв — начальный пароль Васи.

## Формат вывода

Выведите одно число — количество недель, в течение которых Вася сможет использовать исходный и измененные пароли.

## Ограничения

| Параметр            | Значение |
|---------------------|----------|
| Ограничение времени | 2 с      |
| Ограничение памяти  | 256 МБ   |

## Примеры

| Ввод    | Вывод |
|---------|-------|
| abacaba | 15    |
| aaaaaa  | 1     |

# Решение

Каждый новый пароль должен отличаться от исходной строки длиной `N` только двумя символами. Т.е. нужно подсчитать не просто количество уникальных паролей.
Из строки `aabb` нельзя получить `bbaa`.

В общем случае при смене местами двух символов в строке длиной `N` мы выбираем любой из `N` символов и ему в пару любой из `N-1`. Получаем `N * (N-1)` вариантов. 
Но среди этих вариантов есть дубликаты.

Во-первых, при смене символов `1 <-> 3` и `3 <-> 1` мы получаем один и тот же пароль. Значит, нужно поделить результат пополам: `N * (N-1) / 2`.

Во-вторых, смена повторяющихся символов даст нам одинаковые пароли. Нужно посчитать количество дубликатов в зависимости от числа повторяющихся символов исходной строки.
Для примера возьмём тестовую строку `abacaba`. В ней `a` повторяется 4 раза. Значит, для "невалидной пары" мы можем выбрать одну `a` из 4, а вторую `a` - из оставшихся 3. Число дубликатов нужно так же поделить пополам (`1 <-> 3` и `3 <-> 1`, например): `4 * 3 / 2 = 6`.
`b` повторяется 2 раза и даст `2 * 1 / 2 = 1` дубликат.

Наконец, исходная строка - это тоже одна неделя работы с безопасным паролем. К результату в конце добавим единицу:

`(7 * 6 / 2) - (4 * 3 / 2) - (2 * 1 / 2) + 1 = 15`

### Алгоритм решения

- считываем строку в массив Character
- за `O(n)` считаем количество повторов всех символов
- хранение повторов займёт `O(1)` памяти, т. к. алфавит у нас ограничен и не зависит от ввода
- за `O(1)` посчитаем число дубликатов, т. к. дубликаты по ограниченному алфавиту
- по формуле посчитаем итоговый ответ

Итоговая сложность: `O(n)`.
