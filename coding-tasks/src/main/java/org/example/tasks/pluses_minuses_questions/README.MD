# Плюсы, минусы и вопросы

https://coderun.yandex.ru/selections/algorithm-training-september-2025/problems/pluses-minuses-questions/description

## Описание задачи

Дана таблица из `n × m` символов, каждый символ может быть либо `+`, либо `-`, либо `?`. Символ `+` означает число `+1`, символ `-` -
число `−1`, а символ `?` может быть заменён на `+` или `-`.

Определите максимальную достижимую разность суммы в строке с наибольшей суммой и суммы в столбце с наименьшей суммой
после замены всех символов ?.

## Формат ввода

В первой строке записаны два числа `n` и `m` `(1 ≤ n, m ≤ 1000)` — количество строк и столбцов в таблице соответственно.

Далее идут n строк по m символов, содержащие только `+`, `-` и `?`.

## Формат вывода

Выведите одно число — максимально возможную разность.

## Примеры

### Пример 1

| Ввод                            | Вывод |
|---------------------------------|-------|
| 4 3<br>+-+<br>??-<br>?-?<br>++? | 5     |

### Пример 2

| Ввод                                                                                     | Вывод |
|------------------------------------------------------------------------------------------|-------|
| 6 10<br>??+++-?-?-<br>-??+???--+<br>?-+?+-?+--<br>??????--?+<br>++--?--+-?<br>?-?+++?+-? | 12    |

# Решение

Решение делается обычным перебором. При считывании ввода сразу подсчитываем сумму для каждой строки и каждого столбца и сохраняем в массивы. Сам ввод так же сохраняем в двумерный массив.
При этом при подсчёте сумм считаем, что `?` это `+` для строки; `?` это `-` для столбца.

Потом перебираем суммы всех строк с суммами всех столбцов и ищем максимумальную разницу. При этом нужно проверить, если текущая строка и текущий столбец в пересечении имеют `?` (`table[i][j].equals("?")`), то максимальную разницу следует уменьшить на 2. Это из-за того, что у строки и столбца есть общий `?`, который даст либо `+`, либо `-`.

Итоговая сложность: `O(n*m)`.
