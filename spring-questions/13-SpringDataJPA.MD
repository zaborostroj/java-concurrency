### Ответы

#### 1. Что такое Spring Data JPA
Это часть семейства проектов Spring Data, которая облегчает реализацию репозиториев, основанных на JPA. Она позволяет значительно сократить объем шаблонного кода для доступа к данным.

#### 2. Разница между JPA и Hibernate
**JPA (Java Persistence API)** — это спецификация, описывающая правила объектно-реляционного отображения. **Hibernate** — это конкретная библиотека, которая реализует эти правила.

#### 3. Что такое Repository
Это высокоуровневая абстракция для доступа к данным. В Spring Data вы определяете интерфейс репозитория, а Spring автоматически предоставляет его реализацию во время выполнения.

#### 4. Разница между (CrudRepository, PagingAndSortingRepository, JpaRepository)
- **CrudRepository**: Базовый интерфейс с методами CRUD (сохранение, поиск, удаление).
- **PagingAndSortingRepository**: Расширяет CrudRepository, добавляя методы для пагинации и сортировки.
- **JpaRepository**: Расширяет PagingAndSortingRepository и добавляет специфические для JPA методы (например, принудительная отправка изменений в БД `flush`).

#### 5. Что такое EntityManager
Это основной интерфейс JPA для взаимодействия с persistence context. Он используется для выполнения CRUD-операций, создания запросов и управления жизненным циклом сущностей.

#### 6. Что такое Persistence Context
Это своего рода кэш первого уровня, где хранятся все объекты, загруженные из БД или сохраненные в текущей сессии. Он гарантирует, что в рамках одной сессии одна запись БД соответствует одному объекту в памяти.

#### 7. Состояния Entity (Transient, Managed, Detached, Removed)
- **Transient**: Объект создан, но не связан с сессией и БД.
- **Managed**: Объект связан с сессией. Изменения в нем отслеживаются и будут синхронизированы с БД.
- **Detached**: Объект был Managed, но сессия закрылась. Изменения не отслеживаются автоматически.
- **Removed**: Объект помечен для удаления из БД.

#### 8. FetchType LAZY, EAGER
- **EAGER**: Связанные сущности загружаются из БД немедленно вместе с основной сущностью.
- **LAZY**: Связанные сущности загружаются только тогда, когда к ним происходит первое обращение (через Getter).

#### 9. Что такое N+1 проблема
Это ситуация, когда для получения списка из N записей и их связанных данных выполняется 1 запрос для списка и N дополнительных запросов для каждой записи, что сильно снижает производительность.

#### 10. Как решать N+1 (Join Fetch, EntityGraph)
- **Join Fetch**: Использование ключевого слова `FETCH` в JPQL запросе для немедленной загрузки связей одним запросом.
- **EntityGraph**: Аннотация, позволяющая динамически настраивать план загрузки сущностей для конкретных запросов.

#### 11. Что такое Dirty Checking
Механизм Hibernate, который автоматически определяет, были ли изменены поля Managed-сущности, и синхронизирует эти изменения с БД при закрытии транзакции (без явного вызова `save`).

#### 12. Что такое Open Session In View (OSIV)
Паттерн, при котором сессия Hibernate остается открытой до завершения рендеринга View. Это позволяет избежать `LazyInitializationException`, но может привести к неконтролируемым запросам в БД на уровне контроллера или View.
