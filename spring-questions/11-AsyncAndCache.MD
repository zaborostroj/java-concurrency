### Ответы

#### 1. Как работает @Async
Когда метод помечается аннотацией `@Async`, Spring создает прокси-объект, который перехватывает вызов метода и запускает его выполнение в отдельном потоке из пула потоков (`TaskExecutor`).

#### 2. Какие ограничения есть у @Async
- Метод должен быть `public`.
- Вызов метода из того же класса не будет асинхронным (self-invocation).
- Метод может возвращать только `void` или `Future`/`CompletableFuture`.

#### 3. Что такое @EnableAsync
Эта аннотация ставится над конфигурационным классом для активации возможности использования `@Async` в приложении.

#### 4. Как работает @Cacheable
При вызове метода, помеченного `@Cacheable`, Spring сначала проверяет, есть ли результат в кеше для данных аргументов. Если есть — метод не выполняется, а возвращается значение из кеша. Если нет — метод выполняется, и результат сохраняется в кеш.

#### 5. Какие есть аннотации для кеширования (@Cacheable, @CachePut, @CacheEvict)
- **@Cacheable**: Основная аннотация для чтения/записи в кеш.
- **@CachePut**: Принудительно вызывает метод и обновляет значение в кеше (полезно для операций обновления данных).
- **@CacheEvict**: Удаляет запись (или все записи) из кеша (полезно при удалении данных).

#### 6. Что такое Cache Manager
Это центральный компонент Spring, который управляет жизненным циклом кешей. Он абстрагирует работу с конкретными реализациями хранилищ (Redis, Ehcache, Caffeine, Hazelcast или просто `ConcurrentHashMap`).
