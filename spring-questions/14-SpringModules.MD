# Spring Modules

Основные модули Spring Framework:
- **Spring Core** — Базовый модуль, предоставляющий функции IoC и Dependency Injection.
- **Spring Context** — Расширяет Core, добавляя поддержку ресурсов, событий и интернационализации.
- **Spring AOP** — Реализует аспектно-ориентированное программирование для разделения сквозной логики.
- **Spring MVC** — Фреймворк для создания веб-приложений и REST-контроллеров.
- **Spring Data** — Унифицирует доступ к различным типам баз данных (SQL, NoSQL).
- **Spring Security** — Инструментарий для настройки аутентификации, авторизации и защиты приложений.
- **Spring Boot** — Упрощает создание и запуск приложений за счет автоконфигурации и встроенных серверов.
- **Spring Test** — Модуль для поддержки юнит- и интеграционного тестирования компонентов Spring.
