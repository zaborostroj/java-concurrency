### Ответы

#### 1. Что такое IoC (Inversion of Control)
**IoC (Инверсия управления)** — это принцип проектирования, при котором управление жизненным циклом объектов и их зависимостями передается фреймворку (контейнеру), а не самой программе.

#### 2. Что такое DI (Dependency Injection)
**DI (Внедрение зависимостей)** — это паттерн, реализующий IoC. Объекты не создают свои зависимости сами, а получают их извне (через конструктор, сеттер или поле).

#### 3. Какие бывают способы внедрения зависимостей (Constructor Injection, Setter Injection, Field Injection)
- **Constructor Injection**: Рекомендуемый способ. Обеспечивает неизменяемость и обязательность зависимостей.
- **Setter Injection**: Полезно для необязательных зависимостей.
- **Field Injection**: Самый простой, но затрудняет тестирование и нарушает инкапсуляцию.

```java
@Component
public class MyService {
    private final MyRepo repo; // Constructor injection

    public MyService(MyRepo repo) {
        this.repo = repo;
    }
}
```

#### 4. Как получить бин из Spring Context
1. Через `@Autowired` (внедрение).
2. Напрямую из контекста: `context.getBean(MyBean.class)`.

#### 5. Что такое Bean
**Bean** — это объект, управляемый Spring IoC контейнером.

#### 6. Жизненный цикл бина
1. Создание экземпляра.
2. Внедрение зависимостей.
3. Вызов Aware-интерфейсов.
4. BeanPostProcessor (Before).
5. Инициализация (`@PostConstruct`, `init-method`).
6. BeanPostProcessor (After).
7. Использование.
8. Уничтожение (`@PreDestroy`, `destroy-method`).

#### 7. Для чего нужны @PostConstruct и init-методы
Для выполнения логики инициализации после того, как все зависимости внедрены, но до использования бина.
**Их можно использовать для:**
- Проверки обязательных параметров (например, проверка корректности данных, внедренных через `@Value`).
- Установки соединений с внешними ресурсами (базы данных, очереди сообщений, API).
- Заполнения кэшей или начальной загрузки справочных данных.
- Регистрации бина во внешних сервисах или системах мониторинга.
- Запуска фоновых процессов или потоков, необходимых для работы бина.

```java
@Component
public class MyBean {
    @PostConstruct
    public void init() {
        // Выполнится после внедрения зависимостей
    }
}

// Или через Java Config:
@Bean(initMethod = "customInit")
public MyBean myBean() {
    return new MyBean();
}
```

#### 8. Что такое BeanPostProcessor
Интерфейс, позволяющий изменять бины до и после их инициализации.
**Основные сценарии использования:**
- **Создание прокси-объектов**: для реализации сквозной функциональности (AOP), такой как логирование, транзакции (`@Transactional`) или асинхронность (`@Async`).
- **Обработка кастомных аннотаций**: поиск полей или методов, помеченных вашими аннотациями, и выполнение над ними определенных действий.
- **Валидация бинов**: проверка состояния или параметров бина перед тем, как он будет передан в работу.
- **Динамическая настройка**: изменение полей бина или подмена реализации в зависимости от условий окружения.
- **Внедрение зависимостей**: если требуется нестандартная логика инъекции, которую не может выполнить стандартный контейнер.

```java
@Component
public class MyBPP implements BeanPostProcessor {
    @Override
    public Object postProcessBeforeInitialization(Object bean, String beanName) {
        // Логика до инициализации
        return bean;
    }

    @Override
    public Object postProcessAfterInitialization(Object bean, String beanName) {
        // Логика после инициализации (например, создание прокси)
        return bean;
    }
}
```

#### 9. Потокобезопасны ли Spring Beans
По умолчанию бины имеют scope `singleton`. Если они хранят состояние (stateful), они **не потокобезопасны**. Stateless бины (сервисы без полей состояния) потокобезопасны.

#### 10. Что делать если несколько бинов одного типа (@Qualifier, @Primary)
- `@Primary`: помечает бин как приоритетный по умолчанию.
- `@Qualifier("name")`: позволяет указать имя конкретного бина для внедрения.

#### 11. Как инжектить коллекции бинов (List, Set, Map)
Spring автоматически соберет все бины одного типа в коллекцию:
```java
@Autowired
private List<MyInterface> list; // Все реализации интерфейса
```

#### 12. Что такое маркерный интерфейс и как использовать его в Spring
Пустой интерфейс для логической группировки. В Spring можно внедрять все бины, реализующие этот интерфейс, для массовой обработки (например, в BPP).
