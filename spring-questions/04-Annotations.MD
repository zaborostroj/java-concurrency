### Ответы

#### 1. Как работают аннотации в Java
Аннотации — это форма метаданных, которые предоставляют данные о программе, но не являются частью самой программы. Они не влияют напрямую на работу кода, который они аннотируют.
Аннотации обрабатываются:
- **Инструментами компиляции** (например, `@Override` проверяется компилятором).
- **Во время выполнения** (Runtime) через **Reflection API** (Spring находит аннотированные классы и методы).

#### 2. Как создать собственную аннотацию
Собственная аннотация создается с помощью ключевого слова `@interface`.
```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
public @interface MyAnnotation {
    String value() default "default";
}
```

#### 3. Что такое Meta-Annotation (@Target, @Retention, @Documented, @Inherited)
Это аннотации, которые применяются к другим аннотациям:
- `@Target`: указывает, к каким элементам кода можно применить аннотацию (TYPE, METHOD, FIELD и т.д.).
- `@Retention`: указывает, как долго сохраняется аннотация (SOURCE, CLASS, RUNTIME).
- `@Documented`: указывает, что аннотация должна быть занесена в Javadoc.
- `@Inherited`: указывает, что аннотация будет наследоваться дочерними классами.

#### 4. Что такое Composed Annotation
Это аннотация, которая состоит из одной или нескольких других аннотаций. Это позволяет создавать "сокращения" для часто используемых наборов аннотаций.
Пример в Spring: `@RestController` является составной аннотацией, включающей `@Controller` и `@ResponseBody`.
