### Ответы

#### 1. Что такое Authentication
**Аутентификация** — это процесс проверки того, является ли пользователь тем, за кого он себя выдает (например, проверка логина и пароля).

#### 2. Что такое Authorization
**Авторизация** — это процесс проверки прав доступа аутентифицированного пользователя к конкретным ресурсам или действиям (например, имеет ли пользователь роль `ADMIN`).

#### 3. Как работает Spring Security
Spring Security работает на основе цепочки сервлетных фильтров (`DelegatingFilterProxy`). Запрос проходит через ряд фильтров, каждый из которых отвечает за свою задачу (проверка сессии, извлечение токена, проверка прав и т.д.).

#### 4. Что такое SecurityFilterChain
Это цепочка бинов-фильтров, которые упорядочены и применяются к входящему запросу для обеспечения безопасности. В современной конфигурации мы определяем её через бин `SecurityFilterChain`.

#### 5. Как работает JWT-аутентификация
1. Клиент отправляет учетные данные.
2. Сервер проверяет их и возвращает подписанный JSON Web Token.
3. Клиент сохраняет токен и прикладывает его к каждому следующему запросу в заголовке `Authorization: Bearer <token>`.
4. Сервер проверяет подпись токена и, если он валиден, аутентифицирует пользователя.

#### 6. Где в цепочке запросов работает Security
Spring Security работает на уровне сервлетных фильтров, то есть **до** того, как запрос попадет в `DispatcherServlet` и контроллеры Spring MVC.
