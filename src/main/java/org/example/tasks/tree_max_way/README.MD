# Задача

Дано бинарное дерево.

Глубиной пути считается количество вершин на пути от корня до некоторого узла.

Путь называется хорошим, если значения вершин на нём строго возрастают.

Нужно найти максимальную глубину хорошего пути.

## Пример

Дерево:

          5
         / \
        7   3
       / \   \
      8   6   4
     /
    10

Хорошие пути:

5 → 7 → 8 → 10 (длина 4)
5 → 7 (длина 2)

Путь 5 → 7 → 6 не подходит, потому что 6 < 7.

Ответ:

4
