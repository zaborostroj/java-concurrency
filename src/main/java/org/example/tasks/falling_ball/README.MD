# Задача: Мячик на лесенке

## Описание задачи

На вершине лесенки, содержащей N ступенек, находится мячик, который начинает прыгать по ним вниз, к основанию. Мячик
может прыгнуть на следующую ступеньку, на ступеньку через одну или через 2. То есть, если мячик лежит на 8-ой ступеньке,
то он может переместиться на 5-ую, 6-ую или 7-ую.

Определите число всевозможных маршрутов мячика с вершины на землю.

## Формат ввода

Вводится одно число 1≤N≤30.

## Формат вывода

Выведите одно число — количество маршрутов.

## Ограничения

| Параметр            | Значение |
|---------------------|----------|
| Ограничение времени | 1 с      |
| Ограничение памяти  | 256 МБ   |

## Примеры

| Пример   | Ввод | Вывод |
|----------|------|-------|
| Пример 1 | 4    | 7     |
| Пример 2 | 5    | 13    |

# Решение

Для первых трёх ступеней ответы можно захардкодить:

    N == 1 -> 1,0; -> variantsNumber[N] = 1
    N == 2 -> 2,0; 2,1,0; -> variantsNumber[N] = 2
    N == 3 -> 3,0; 3,1,0; 3,2,0; 3,2,1,0; -> variantsNumber[N] = 4

Для последующих ступеней i ответ равен сумме вариантов для ступеней `i-3`, `i-2`, `i-1`:

    N == 4 -> 4,3 variantsNumber[3]; 4,2 variantsNumber[2]; 4,1 variantsNumber[1] -> 4 + 2 + 1 = 7
    N == 5 -> 5,4 variantsNumber[4]; 5,3 variantsNumber[3]; 5,2 variantsNumber[2] -> 7 + 4 + 2 = 13
