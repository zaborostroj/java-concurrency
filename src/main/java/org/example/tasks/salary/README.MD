# Задача: Расчет премий сотрудников

https://coderun.yandex.ru/selections/algorithm-training-september-2025/problems/bonuses-from-the-boss/description

## Описание задачи

Начальник решил выдать премии своим сотрудникам. Для этого он выписал всех сотрудников в порядке возрастания
профессионализма, а также выписал для каждого сотрудника количество выходных дней, в которые он работал, для i-го
сотрудника это число a_i.

Подсчитать премию для каждого сотрудника решил по следующей формуле: для сотрудника i он подсчитывает количество таких
сотрудников с номерами j<i, что j+a_j>i. Затем он умножает это количество на a_i и таким образом вычисляет размер премии
i-го сотрудника.

Определите суммарный размер премий всех сотрудников.

## Формат ввода

В первой строке вводится число n (1≤n≤100000) — количество сотрудников.

Вторая строка содержит n целых чисел a_i (0≤a_i≤n) — количество выходных дней, которые отработали сотрудники.

## Формат вывода

Выведите суммарный размер премий.

## Примечание

Ответ на тест, приведенный в примере, получается по формуле: 0×4+1×2+2×2+2×4=14

# Решение

4 сотрудника, выходные [4, 2, 2, 4].

Каждый работник `i` может влиять на отрезок из нескольких последующих.
Левая граница отрезка `l = i + 1`. Правая граница отрезка `r = i + ai -1`. Если  `l > r` - то работник ни на кого не влияет (случаи с 0 или 1 выходным). Возьмём массив, на 1 больший, чем количество работников. В этом массиве для каждого сотрудника, кроме последнего, сделаем `arr[l]++`, `arr[r + 1]--`. Массив взят больше на 1 для удобства - так убираются проверки в коде для границ отрезков, влияющих на последнего работника.

В следующем проходе можно подсчитать, сколько сотрудников слева влияет на премию текущего работника: `active += activeInfluencers[i]` и к результату прибавляем `active * ai`.


```
                    0  1  2  3
            i[0]=4:    [      ]
            i[1]=2:       []
            i[2]=2:          []
            i[3]=4:
 activeInfluencers: 0  1  2  2

 result = 0 * 
```

Алгоритм содержит два линейных прохода по всем элементам, общаая сложность O(n).
