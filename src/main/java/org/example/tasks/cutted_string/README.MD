# Разрезанная строка

https://coderun.yandex.ru/selections/algorithm-training-september-2025/problems/split-line/description

## Описание задачи

Строка `s` была разрезана на `k` частей одинаковой длины. По строке `s` и перемешанным частям определите, в каком
порядке их нужно склеить, чтобы получить строку `s`.

## Формат ввода

В первой строке записано два числа `n` и `m` (1 ≤ n, m ≤ 10⁶) — длина строки и количество кусков соответственно.

Во второй строке записана строка `s` (1 ≤ |s| ≤ 10⁶) — строка, которую необходимо получить.

В `i`-й из следующих `m` строк дана строка `t_i` — описание `i`-го куска исходной строки.

Гарантируется, что `n` делится на `m` и из данных кусков можно составить исходную строку.

## Формат вывода

Выведите `m` различных целых чисел `a_i` (1 ≤ a_i ≤ m), таких, что если заменить число на `i`-й позиции куском с номером
`a_i` и склеить получившиеся куски, получится исходная строка.

Если ответов несколько, выведите любой.

## Ограничения

| Параметр            | Значение |
|---------------------|----------|
| Ограничение времени | 3 с      |
| Ограничение памяти  | 256 МБ   |

## Примеры

| Ввод                                         | Вывод |
|----------------------------------------------|-------|
| 12 3<br>cabacaqwerty<br>erty<br>caba<br>caqw | 2 3 1 |

# Решение

Разбиваем исходную строку на `m` частей и из них составляем мапу:
* ключ - это сама подстрока
* значение - список позиций в исходной строке


    cabacaqwertyerty
    caba => {0}
    caqw => {1}
    erty => {2, 3}

Далее начинаем читать кусочки исходной строки в цикле. Результат цикла - массив. Позиция элемента в массиве - это позиция считанной подстроки в исходной строке. Значение элемента массива - порядковый номер считанного кусочка.

Составление хеш-мапы даёт сложность `O(n / m)`.
Цикл с перебором входных данных даёт сложность `O(n * m)`, т. к. мы перебираем `m` кусочков и удаляем элемент из листа длиной `n` (для случая, когда строка состоит из одинаковых кусочков в один символ).

Итоговая сложность: `O(n * m)`.
