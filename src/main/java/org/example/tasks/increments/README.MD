# Табло с инкрементом

https://coderun.yandex.ru/selections/algorithm-training-september-2025/problems/incremental-scoreboard/description

**Сложность:** Средняя  
**Статус:** Решена

## Описание задачи

На табло было написано число n. Каждую секунду к числу прибавляется последняя цифра этого числа. Определите, какое число
будет отображаться на табло через k секунд.

## Формат ввода

В единственной строке записаны два числа n и k (0 ≤ n, k ≤ 10^9) — начальное число и количество секунд соответственно.

## Формат вывода

Выведите одно число x, которое будет отображаться на табло через k секунд.

## Ограничения

| Параметр            | Значение |
|---------------------|----------|
| Ограничение времени | 1 с      |
| Ограничение памяти  | 256 МБ   |

## Примеры

| Ввод | Вывод |
|------|-------|
| 1 10 | 44    |
| 5 1  | 10    |

# Решение

Можно решить задачу в лоб - в одном цикле за `O(n)`. 

Оптимальное решение - за `O(1)`.

Можно заметить закономерность: последние цифры при предложенной операции всегда повторяются:

Для последних цифр `0` и `5` - цикла нет.
Для нечётных цифр цикл начинается со второй секунды, для чётных - с первой.
Один цикл состоит из четырёх сложений и даёт прибавку `2 + 4 + 8 + 6 = 20`. 
При расчёте конечной суммы вычисляем количество полных циклов `(int) k / 4` и количество сложений, которые нужно посчитать за оставшийся неполный цикл `k % 4`.
Результат - это сумма полных циклов и оставшихся сложений с учётом чётности входящего числа.

Результат нужно обязательно хранить в `long`, т. к. по условию задачи `n, k <= 10^9. Многие ошибки в закрытых тестах лечились правильным приведением типов.

Итоговая сложность: `O(1)`.
